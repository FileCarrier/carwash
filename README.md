# 🚗 Шаблон сайта для автомоек

Готовый лендинг с системой онлайн-записи, калькулятором стоимости и отправкой заявок в Telegram.

## 🎯 Возможности

- **Онлайн-запись** — 3-шаговая форма с выбором услуг, даты и времени
- **Калькулятор стоимости** — расчёт цены с учётом класса авто и доп. опций
- **Telegram-уведомления** — заявки автоматически отправляются владельцу
- **Адаптивный дизайн** — отлично выглядит на ПК и мобильных
- **Лёгкое редактирование** — все настройки в одном файле `src/config.ts`

## ⚙️ Настройка под конкретную мойку

### 1. Откройте файл `src/config.ts`

### 2. Заполните основную информацию:
```typescript
companyName: "Название мойки",
address: "Адрес",
phone: "+7 (XXX) XXX-XX-XX",
email: "email@example.com",
workingHours: "Ежедневно 9:00 — 21:00",
```

### 3. Настройте Telegram-бота:
1. Создайте бота через [@BotFather](https://t.me/BotFather) в Telegram
2. Получите токен бота
3. Узнайте свой Chat ID (напишите боту, затем откройте `https://api.telegram.org/bot<TOKEN>/getUpdates`)
4. Впишите данные:
```typescript
telegram: {
  botToken: "123456:ABC-DEF...",
  chatId: "123456789",
},
```

### 4. Настройте услуги и цены:
```typescript
services: [
  {
    id: "exterior",
    name: "Мойка кузова",
    description: "Описание услуги",
    icon: "droplets", // droplets, car, sparkles, gem
    duration: 20, // минут
    basePrice: 500, // базовая цена
    options: [
      { id: "opt1", name: "Доп. опция", price: 200 },
    ],
  },
]
```

### 5. Настройте классы авто:
```typescript
carClasses: [
  { id: "sedan", name: "Седан", multiplier: 1.0 },
  { id: "suv", name: "Кроссовер", multiplier: 1.3 },
]
```

## 🎨 Кастомизация дизайна

### Цветовая схема
Основные цвета — в компонентах. Замените `cyan-500` / `blue-600` на нужные:
- Tailwind классы: `emerald`, `purple`, `orange`, `rose` и т.д.
- Или используйте кастомные HEX-цвета

### Шрифты
В `index.html` подключён Inter. Замените на другой шрифт из Google Fonts.

### Секции
Каждая секция — отдельный компонент в `src/components/`. Можно добавлять/удалять/менять порядок в `src/App.tsx`.

## 📁 Структура проекта

```
src/
├── config.ts              ← ГЛАВНЫЙ ФАЙЛ НАСТРОЕК
├── types.ts               ← TypeScript типы
├── App.tsx                ← Сборка всех секций
├── index.css              ← Глобальные стили
├── components/
│   ├── Header.tsx         ← Шапка с навигацией
│   ├── Hero.tsx           ← Главный экран
│   ├── Services.tsx       ← Услуги и преимущества
│   ├── PriceCalculator.tsx ← Калькулятор стоимости
│   ├── Booking.tsx        ← Форма записи + Telegram
│   ├── Reviews.tsx        ← Отзывы клиентов
│   ├── Contacts.tsx       ← Контакты и соцсети
│   └── Footer.tsx         ← Подвал
```
